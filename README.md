# GetReadyAI

This repository contains the source code for GetReadyAI.

## Project Structure

- `backend/`: Python Flask backend application.
- `frontend/`: Static frontend files (HTML, CSS, JS).

## Running the Application

To start the application, run the `start.sh` script from the root directory:

```bash
./start.sh
```

This script will:
1. Install the necessary Python dependencies.
2. Start the Flask server on port 5001.

You can then access the dashboard at `http://localhost:5001`.

## Development

The backend code is located in `backend/run.py`.
The frontend code is located in `frontend/index.html`.
